## Основные компоненты

### Task

Модель задачи, реализованная во 2-й лабораторной работе. Содержит валидируемые атрибуты:

- `id` — уникальный идентификатор  
- `description` — описание задачи  
- `priority` — приоритет задачи  
- `status` — статус задачи  
- `created_at` — время создания  

Также предоставляет вычисляемые свойства:

- `is_ready` — задача готова к выполнению  
- `is_completed` — задача завершена  

---

### TaskQueue

Класс `TaskQueue` представляет собой очередь задач и поддерживает:

- хранение задач;
- добавление одной или нескольких задач;
- повторяемую итерацию по очереди;
- ленивую фильтрацию;
- работу с готовыми и завершёнными задачами.

Основные методы:

- `add(task)` — добавить одну задачу  
- `extend(tasks)` — добавить несколько задач  
- `__iter__()` — вернуть новый итератор по очереди  
- `__len__()` — вернуть количество задач  
- `filter(predicate)` — общий ленивый фильтр  
- `filter_by_status(status)` — фильтр по статусу  
- `filter_by_priority(min_priority, max_priority)` — фильтр по диапазону приоритета  
- `iter_ready()` — генератор готовых задач  
- `iter_completed()` — генератор завершённых задач  

---

## Идея решения

`TaskQueue` хранит задачи во внутреннем списке, а метод `__iter__()` каждый раз возвращает **новый итератор**. Благодаря этому очередь можно проходить повторно:

```python
for task in queue:
    ...

for task in queue:
    ...
```

Ленивые операции фильтрации реализованы через `yield`, поэтому элементы не собираются в отдельный список заранее, а отдаются по одному по мере обхода:

```python
for task in queue.filter_by_status("new"):
    print(task)
```

Это делает решение более эффективным и соответствует требованиям лабораторной работы по использованию генераторов и ленивой обработки.

## Пример использования

```python
from src.receiver import receive_tasks
from src.sources import GeneratorSource
from src.task_queue import TaskQueue

source = GeneratorSource(5)
tasks = receive_tasks(source)

queue = TaskQueue(tasks)

for task in queue:
    print(task)

high_priority = list(queue.filter_by_priority(min_priority=4))
completed_count = sum(1 for task in queue if task.is_completed)
```
